# Preparación para GitHub

El ZIP contiene código, skills, parámetros personales de WriteGer, pruebas e instrucciones; excluye PDFs, datos de investigaciones, entornos, cachés y configuración local de Git. Las denominaciones originales de los activos se conservan para trazabilidad, no como entregas de desarrollo.

Descomprime el ZIP, crea ScientificWriterGer en GitHub y sube el contenido de la carpeta. GitHub Actions ejecuta los controles del paquete al subir cambios. El instalador crea una skill autocontenida; los paquetes y guías multiplataforma están en exports/.

## Alcance real

Las herramientas ejecutables verifican registros, hashes, tokens numéricos y estilometría española. Las skills orientan un agente; no son un motor autónomo que haga investigación sin herramientas y documentos. Gemini y Claude no están conectados automáticamente. La compatibilidad estilométrica no demuestra validez científica. PDF ofrece una ruta alternativa comprobada, con lector identificado; la extracción depende de la maquetación.
